# Contributor Covenant Code of Conduct

## Our standard

We want ResearchForge to be a professional, inclusive and technically rigorous
project. Participants are expected to communicate respectfully, accept
constructive review, and focus on evidence, user impact and maintainable code.

Unacceptable behaviour includes harassment, discrimination, threats, deliberate
disruption, publishing private information, and any other conduct that would
make a reasonable contributor feel unsafe or unwelcome.

## Enforcement

Report a concern privately using the process in [SECURITY.md](SECURITY.md).
Include the relevant links, timestamps and context. Maintainers will review
reports confidentially, may request clarification, and will take proportionate
action up to removing participation from project spaces.

This code applies to issues, pull requests, discussions, chat, documentation,
events and any other project-managed space.
