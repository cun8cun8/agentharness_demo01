# ResearchForge P0 研发 Backlog

> 文档定位：P0 开发任务拆解
> 目标：把 Coding Agent Harness 最小闭环拆成可开发、可验收的任务

## 1. 开发原则

- 先完成主链路，再补体验细节；
- 先做确定性状态机，再扩展更自由的 Agent 行为；
- 所有工具调用必须结构化记录；
- 所有高风险操作必须经过 Policy 检查；
- 所有任务结果必须生成报告或失败报告；
- Benchmark 和 Data Flywheel 必须基于真实 Agent Run。

## 2. Sprint 1: 基础任务系统

目标：建立 Task、Run、Trace 的基础模型和接口。
