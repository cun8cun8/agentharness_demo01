# ResearchForge 前端工作台

默认入口已迁移为 Next.js App Router + React + TypeScript 中文工作台。接口失败会显示错误，不会静默填入演示记录。

## 启动

```powershell
npm ci
$env:RESEARCHFORGE_BACKEND_URL='http://127.0.0.1:8001'
npm run dev
```

然后打开 `http://127.0.0.1:3011`。`npm run build` 构建，`npm start` 在 3010 提供生产服务。

前端通过同源代理访问后端，部署时必须在构建阶段设置 `RESEARCHFORGE_BACKEND_URL`。

## 原生页面

- `/tasks`：中文任务创建、预算、筛选、分页和详情。
- `/runs`：按项目、仓库分支、模型、策略和时间查看运行历史；支持工具输入输出、基线/验证日志、Diff、SSE/轮询、单条或批量取消/重试，并可导出当前筛选结果 CSV。
- `/research`：研究简报、实验执行、自主研究循环。
- `/datasets`：轨迹/偏好对创建、人工审核、训练标记与数据导出。
- `/training`：离线 SFT/DPO 准备、启动、状态同步、取消与日志。
- `/registry`：模型版本、真实评测发布门禁、历史和回滚确认。
- `/system`：用户创建/编辑、角色、账户状态、依赖检查和企业身份。

## 验证

`npm run check`、`npm run build`、`npx playwright test`。
浏览器测试需要隔离预览服务，默认 3011；环境变量 `RESEARCHFORGE_PREVIEW_URL` 可覆盖地址，
`PLAYWRIGHT_EXECUTABLE_PATH` 可指定已安装 Chromium。测试会写入验收记录，不对生产地址运行。
默认断言等待时间为 15 秒，适用于本地 Docker 全栈；可通过 `RESEARCHFORGE_E2E_EXPECT_TIMEOUT` 覆盖。
截图输出到 `test-results`，后端配置和未完成事项见根目录 `DELIVERY.md`。

## 兼容工作台

下面的既有高级功能保留在 `/legacy`，也可以通过 `npm run legacy` 单独启动原静态页面。
这些描述不代表实际云服务或真实流量灰度已完成生产验收。

研究区支持导入文本或 PDF 文件路径、查看来源文件元数据和导入任务、选择证据挂载到研究简报、导出证据 JSONL，以及对引用执行通过/退回审核。
研究区还支持 10 题 Research Benchmark 批量验收，并提供验收报告导出。数据飞轮支持 Trace 审核、偏好对审核、记忆归档和数据集版本导出；运行中的 Trace 通过 SSE 推送，并在连接异常时自动重连。
研究笔记本会在配置的沙箱中执行可重复性检查，并展示执行状态与平台遥测。
平台状态区展示 Job 队列、完成/失败计数，以及模型调用、评测、策略对比、发布门禁、代码验收、研究验收和仓库同步的结构化结果摘要。
工作区管理支持编辑任务数量、并发运行数和每日成本上限，并实时显示当前使用量与剩余额度；Redis 外置 Worker 会显示为外置模式。
模型试调会展示尝试次数、回退原因和成本估算，方便判断真实模型网关是否可用。
发布门禁会展示候选、灰度、正式发布或阻断状态，并显示灰度比例。
评测历史提供验收报告导出链接，报告包含目录校验、策略约束、发布门禁记录和任务级评分细节。
任务详情会调用上下文快照接口，合并展示当前任务的关联后台任务、Trace 候选、偏好对和推荐记忆。
平台能力区展示内置工具清单；后端同时提供工具策略预检接口，用于在不执行工具的情况下查看安全策略判定。
扩展清单支持检查健康、启用/停用扩展、试调 MCP/Skill、测试 Hook，并展示最近 Hook 派发记录。
策略区展示预检查、重试、评审开关，以及重试次数、最大修改文件数/行数和是否允许修改测试等运行阈值；Critic 详情会显示本次评审采用的阈值。
审批区支持通过或拒绝工具审批；通过后可直接恢复运行，并显示审批被哪个新运行消费。
任务筛选支持按工作区过滤；平台顶部可切换当前用户，后端会按角色限制写入操作。
暂停的 Agent Job 可直接在队列列表中恢复；运行文件树会显示总量和截断提示。
列表接口都使用有界分页，前端会限制并发请求并在接口短暂抖动时自动重试，避免数据多时直接退回演示状态。
数据飞轮区展示质量报告，并提供统一训练包导出入口，便于收集 SFT 轨迹、偏好记录、失败样本和 active 记忆。
当前成员切换后，控制台会按角色隐藏或禁用没有权限的写入、审批、评测、研究和平台治理操作；后端仍会再次执行 RBAC 校验。
自定义代码任务优先使用执行配置中的源码路径和补丁；没有可用补丁时会明确提示 `PATCH_NOT_AVAILABLE`，不会静默套用其他样例任务的补丁。
