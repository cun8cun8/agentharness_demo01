# Support

## Supported release line

- The latest tagged stable release receives security fixes and critical bug
  fixes.
- The `main` branch is the active development line and may change between
  releases.
- Older releases are supported only when a release note explicitly says so.

## Where to ask

- Reproducible product defects: use the Bug report issue form.
- Improvements: use the Feature request issue form.
- Deployment questions: include the deployment mode and sanitized preflight
  output; remove tokens, private repository URLs and customer data.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and report
  privately. Do not open a public issue for an unpatched vulnerability.

Please include the release or commit, operating system, deployment mode, exact
steps to reproduce, expected behaviour, actual behaviour and sanitized logs.
Issues without enough detail may be closed until they can be reproduced.
